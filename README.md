# Voice Clipper

Windows x64向けの、動画・音声から複数範囲の音声を取り出すアプリです。素材や音声をサーバーに送信しません。

## 起動

`release/win-unpacked/Voice Clipper.exe` を開いてください。配布フォルダー全体が必要です。インストールやシステムへのFFmpeg導入は不要です。初回起動時、署名のないアプリとしてWindowsの確認が表示される場合があります。

## 操作

1. 「素材を開く」で動画・音声を選びます。
2. 波形上をドラッグして範囲を追加します。クリックで再生位置を移動します。
3. 範囲の端をドラッグするか、一覧の開始・終了時刻（秒、小数点以下3桁）を入力して調整します。数値はEnterまたはフォーカス移動で確定します。
4. 名前と「試聴」で内容を確認します。重なる範囲もそれぞれ書き出せます。
5. MP3またはWAVを選び、「音声を書き出す」で保存先を指定します。

Space: 再生・停止 / Delete: 選択範囲を削除。入力欄の操作中はショートカットを無効にします。倍率で拡大し、横スクロールで移動できます。範囲が多い場合はタイムラインを縦にスクロールしてください。

「保存」で編集データ（JSON）を保存し、「編集データを開く」で再開できます。素材自体は含まれないため、元ファイルも保管してください。移動した素材は読み込み時に再指定できます。

MP3は192kbps、WAVは16bit PCMです。素材のサンプルレートとチャンネル数を維持し、先頭の音声トラックを使用します。MP3で維持できない多チャンネル／高サンプルレート素材はWAVを選んでください。出力は開始時刻順です。同名ファイルには枝番が付きます。キャンセル時は処理中のファイルを削除し、完了済みファイルを残します。

初版は素材1つの編集に対応します。直接再生できない素材は一時プレビューへ変換するため、追加の処理時間とディスク容量が必要です。書き出しは常に元の素材から行います。非常に長い素材の波形は表示用に間引きますが、範囲時刻はミリ秒単位で指定できます。

## 開発

Node.js 24 / npm、Windows x64を使用します。

```powershell
npm.cmd ci
node scripts/prepare-tools.mjs
npm.cmd start
npm.cmd test
npm.cmd run package
npm.cmd run test:desktop
```

`prepare-tools.mjs` は既定で `C:/Program Files/ffmpeg` からツールとライセンスをコピーします。別の配置の場合は `FFMPEG_ROOT` に `bin/ffmpeg.exe`、`bin/ffprobe.exe`、`LICENSE`、`README.txt` が入ったフォルダーを設定してください。実行時にはPATHを参照しません。`package-lock.json` を含めて依存を固定しています。

`npm test` は実際のFFmpegで素材生成、範囲書き出し、内容と時間、形式、異常系を検証します。`test:desktop` は配布exeをPlaywrightで起動し、UI・IPC・保存・再開・書き出しを確認します。結果は `test-results/` に保存されます。

同梱ツールの情報は `THIRD_PARTY_NOTICES.txt` と `resources/tools/` を参照してください。公開配布する場合は同梱するGPLバイナリとリンク先ライブラリーの対応ソース提供も必要です。
